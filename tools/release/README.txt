ShardStroke {VERSION} (alpha), Windows x64

Run ShardStroke.exe. File > Open loads a project of the industry-standard texturing software or an OBJ mesh.

This is an early preview: expect missing features and rough edges. Settings are stored in
%APPDATA%\ShardStroke. The Open Image Denoise DLLs next to the executable enable the "AI denoise"
option of the path-traced viewport; the program runs without them.

Source, issues and documentation: https://github.com/stokeer/ShardStroke
